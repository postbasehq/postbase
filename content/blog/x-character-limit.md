**The X (Twitter) character limit is 280 characters per post on a free account.** X Premium subscribers can write posts of up to 25,000 characters. Replies and quote posts have the same limits, DMs allow up to 10,000 characters, and your bio is limited to 160. Links always count as 23 characters, and emojis count as 2.

Here's every limit on X in one place, how X counts characters (it isn't one-for-one), and how to fit more into a post. Checked on 10 November 2026.

## Every X character limit at a glance

| What | Limit |
| --- | --- |
| Post (free account) | 280 characters |
| Post (X Premium, any tier) | 25,000 characters |
| Reply | Same as a post: 280, or 25,000 with Premium |
| Quote post | Same as a post; the quoted post doesn't count |
| Direct message | 10,000 characters |
| Bio | 160 characters |
| Display name | 50 characters |
| Username (@handle) | Up to 15 characters: letters, numbers and underscores |
| Location | 30 characters |
| Poll choice | 25 characters each, up to 4 choices |
| Image alt text | 1,000 characters |
| List name | 25 characters |
| List description | 100 characters |

Sources: X's guide to [counting characters](https://docs.x.com/fundamentals/counting-characters) and the [X Premium help page](https://help.x.com/en/using-x/x-premium).

## How X counts characters

X doesn't simply count letters. It uses a weighted count:

| What you type | Counts as |
| --- | --- |
| Latin letters, numbers, punctuation and spaces | 1 each |
| Emojis, including ones with skin tones or joined together | 2 each |
| Chinese, Japanese and Korean characters | 2 each |
| Any link, however long | 23 |
| Photos, videos and GIFs you attach | 0 |
| @usernames added automatically at the start of a reply | 0 |
| @usernames you type yourself | 1 per character |

So a post in English can be 280 letters, but a post in Japanese only about 140 characters, and a 120-character URL takes the same 23 as a short one. That's why counting in a normal text editor can tell you a post fits when X says it doesn't.

## The X Premium character limit

All three X Premium tiers (Basic, Premium and Premium+) can post up to **25,000 characters** in a post, reply or quote. Everyone can read long posts; only subscribers can write them.

In the timeline, a long post is cut off after the first few lines with a "Show more" link. Most people decide whether to tap from those first lines alone, so treat them like a headline.

Premium also lets you edit a post within an hour and publish **Articles**, X's format for long, formatted writing with headings and images.

## Do links and images count toward the limit?

**Links:** yes, always 23 characters, whatever their real length. X wraps every link in its own t.co short link.

**Photos, videos and GIFs:** no. Attach up to four images, one video or one GIF without losing any characters.

**Quoted posts:** no. When you [quote a post](/blog/how-to-quote-tweet), only your own comment counts.

## How to fit more into 280 characters

1. **Write a thread.** For anything longer than one idea, split it into posts of up to 280 characters each. Here's [how to write a thread people finish](/blog/how-to-write-an-x-thread).
2. **Put the detail in an image.** A screenshot of a chart, a code snippet or a list costs nothing against the limit. Add alt text so everyone can read it.
3. **Cut filler.** "In order to", "I think that", "really" and "very" rarely add anything.
4. **Use numerals and symbols.** "3" not "three", "&" in casual posts.
5. **Link instead of explaining.** A link is 23 characters, however much is behind it.

## Why the limit is 280

Twitter started at 140 characters in 2006 so a tweet fitted in a single SMS text message with room for the username. It doubled to 280 in November 2017 for most languages; Chinese, Japanese and Korean stayed at 140 because their characters carry more meaning each, which is where the weighting comes from. Premium's longer posts arrived in 2023.

## Frequently asked questions

### What is the character limit on X (Twitter)?

280 characters per post for free accounts, and 25,000 characters for X Premium subscribers. Links always count as 23 characters and emojis as 2.

### How many characters can you have with X Premium?

Up to 25,000 characters per post, reply or quote, on every Premium tier.

### What is the character limit for X DMs?

10,000 characters per direct message.

### What is the X bio character limit?

160 characters. Your display name can be up to 50 characters and your username up to 15.

### Do emojis count as two characters on X?

Yes. Every emoji counts as 2 characters, even combined ones such as a family emoji or an emoji with a skin tone.

### Do spaces count as characters on X?

Yes. Spaces and line breaks each count as one character.

### Do links count toward the character limit?

Yes. Every link counts as exactly 23 characters, however long the actual URL is.

### Do replies have the same character limit?

Yes: 280 characters, or 25,000 with Premium. The @usernames X adds automatically at the start of a reply don't count.
