## List media

```bash
curl "https://www.postbase.so/api/v1/media?type=video" \
  -H "Authorization: Bearer pb_live_…"
```

`GET /media` returns the newest 50 files in your workspace's media library.
Filter with `?type=image` or `?type=video`, and `?search=` to match part of a
file name. Pass the `id` values as `media_ids` when [creating a post](/api/posts).

```json Response
{
  "media": [
    {
      "id": "…",
      "name": "launch.mp4",
      "type": "video/mp4",
      "size_bytes": 18350212,
      "url": "https://…",
      "created_at": "2026-10-08T09:00:00.000Z"
    }
  ]
}
```

Files are uploaded in the Postbase app (**Media**); the API doesn't upload them.
