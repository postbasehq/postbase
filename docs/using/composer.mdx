The composer is where you write a post, pick channels, attach media, and
schedule it.

## Writing a post

1. Pick the **channels** to publish to (the circular icons at the top).
2. Write your post. The character counter and per-platform checks update live —
   e.g. X's 280-character limit, or that TikTok needs media.
3. Attach [media](/using/media) or [generate](/ai/generate) an image.
4. [Schedule](#scheduling) a time, or leave it empty to save a draft.

## Threads and comments

Use **Add comment / post** to add more posts. On thread-capable platforms
(X, Bluesky, Mastodon) these publish as a thread. On others (like LinkedIn) the
extra parts publish as a first comment.

<Tip>
  Drag the grip handle on any post to reorder it. The thread connectors show how
  the posts chain together.
</Tip>

## Scheduling

Open **Schedule a time** to pick a date and time. Postbase publishes in your
workspace timezone (shown in the picker). Leave it empty to **save as a draft**.

You can also set a **repeat** cadence so a post re-publishes on a fixed schedule
until you delete it.

## Load a draft

Use **Load draft** to pull an existing draft back into the composer — handy for
picking up where you left off.
