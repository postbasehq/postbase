The media library stores images and video you can reuse across posts.

## Uploading

Drag & drop files onto the uploader, or **browse** to pick them. Uploads go
straight to object storage in resumable chunks, so a dropped connection won't
cost you the whole file.

- **Size**: up to 1&nbsp;GB per file.
- **Types**: MP4, MOV, WebM (video) and JPG, PNG, WebP, GIF (image).

## Managing files

- **Search** by name and **filter** by images or videos; **sort** by newest,
  largest, or name.
- Click a file to open a **preview**, where you can **rename** it, **copy** its
  URL, or **use it in a new post**.
- Turn on **Select** to pick several files and delete them at once.

<Note>
  Deleting a file removes it from your library and storage. Posts that already
  used its URL keep working until you replace them.
</Note>
