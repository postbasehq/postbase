⚠️ **These are draft templates, not legal advice.** Have a qualified UK solicitor review
them before publishing on postbase.so. Berkway will likely need to register with the ICO as
a data controller before processing personal data at scale.

## Before publishing — fill these placeholders

- [ ] `[company number]` — Berkway Group Limited's Companies House number
- [ ] `[registered office address]`
- [ ] `[ICO registration reference]` — register at ico.org.uk
- [ ] `[Payment processor, e.g. Stripe]` — the actual processor
- [ ] `[Email provider, e.g. Resend]`
- [ ] `[AGPL-3.0]` — confirm the open-source licence
- [ ] `[30–90] days` — set your account-deletion retention window
- [ ] Confirm the sub-processor list (Supabase, Vercel, Inngest, payment, email) matches
      what you actually deploy
- [ ] Update **Last updated** dates on publish
- [ ] Solicitor review — especially billing/auto-renewal, liability, and consumer rights

## Why these matter now

A live **Privacy Policy URL** is a hard prerequisite for the X, LinkedIn, and Meta app
submissions (see [../docs/CRITICAL_PATH.md](../docs/CRITICAL_PATH.md)). Host these at
`postbase.so/privacy` and `postbase.so/terms` so the gate applications can reference them.
